## Extreme refinement

**Update in progress:** the audio examples for this comparison will be added here.

This comparison uses an extended-technique cello input and the Extreme processing behaviour before gain/filter correction, followed by three adjustments:

- −13 dB / 2000 Hz.
- −10 dB / 1500 Hz.
- −10 dB / 2500 Hz, the composer's subsequent preference.

The comparison examines how listening and visual representations informed the adjustment. The outputs are distinct stochastic realisations of the same source and specified conditions.

Until the examples are posted, the supporting recordings and analysis data can be requested by email.

## Gestures and blend

**Update in progress:** the audio examples for this comparison will be added here.
