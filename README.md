# TEIA

TEIA is an evolving environment for shaping musical textures through performance, listening, and design. Developed by Micael Antunes in Max with Csound, it brings together sound processing, gesture-based control, and tools for listening and analysis.

**Repository update in progress.** The software, documentation, and companion audio examples are currently being organised. Additional materials will be added here.
